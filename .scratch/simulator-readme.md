## The Problem: Notification Blindness

Standard to-do and reminder applications (Todoist, TickTick, Google Tasks, Apple Reminders) deliver task alerts via passive lock-screen banners. 

When a phone buzzes with a dozen social media notifications, chat pings, and delivery updates, the human brain unconsciously swipes away reminders without reading them. For critical deadlines, flight check-ins, or daily medication, a swiped notification is a catastrophic failure mode.

**Productivity Caller** solves notification blindness by replacing passive push notifications with **full-screen automated incoming phone calls**.

## Interactive Web Simulator Features

Experience the application flow directly in your browser:
* **Natural Language Parsing Demo:** Test deterministic datetime extraction across 80+ speech patterns (*"Call dentist tomorrow at 4:30 pm"*, *"Review PR in 45 minutes"*).
* **Incoming Call Screen:** Simulates Android Telecom full-screen call takeover with high-friction active dismissal actions.
* **Sound & Vibration Effects:** Native synthesized audio simulating phone ringer audio streams.
* **Sunroom Cat Companion:** Interactive post-call companion state machine tracking completed focus streaks.

## Feature Comparison Matrix

| Evaluation Metric | Productivity Caller | Native Clock / Alarms | To-Do Apps (Todoist / TickTick) | Extreme Alarms (Alarmy) |
|---|---|---|---|---|
| **Alert Mechanism** | **Full-Screen Phone Call** | Continuous Audio Overlay | Passive Banner Notification | Mission / Puzzle Lockout |
| **Dismissal Friction** | **High (Call Response)** | Medium (Single Swipe) | Zero (Single Swipe) | Very High (Math / Typing) |
| **Lock-Screen Penetration** | **100% (Overrides Screen)** | 100% (Full Alarm) | Low (Notification Tray) | High (Device Admin) |
| **Natural Language Input** | **Yes (80+ Patterns)** | No (Manual Wheels) | Yes (Paid Tiers) | No (Manual Pickers) |
| **Cloud Dependency** | **100% Local / Offline** | 100% Local | Cloud Mandatory | Cloud Sync Optional |
