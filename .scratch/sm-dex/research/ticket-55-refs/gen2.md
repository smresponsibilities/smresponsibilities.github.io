# Gen II extra references

Retrieved 2026-09-09 from WikiDex's MediaWiki API. The API request used `action=query&prop=imageinfo&iiprop=url|size|sha1` with 20 file titles from the local `wikidex-search.json` index. Each source title is an EP122–EP274 Johto anime Pokédex capture, with one distinct episode per row. Original files were downloaded unchanged from the API's `imageinfo.url` and stored under `gen2/`.

These are visual references for screen framing, colored scan fields and image placement. Wider views also show the directional pad, neighboring keys, lower lens and right leaf. They do not establish exact dimensions, hidden faces or hinge order. Lighting and animation drawings vary across episodes. WikiDex hosts the file pages and CDN originals; the animation is the visual evidence.

The current set is deliberately episode-diverse: EP123, EP127, EP140, EP145, EP154, EP160, EP163, EP173, EP190, EP205, EP210, EP216, EP218, EP222, EP232, EP236, EP249, EP250, EP261, and EP266. Hashes in `gen2.json` are the API-reported SHA-1 values and support duplicate checks against the earlier catalogue.
