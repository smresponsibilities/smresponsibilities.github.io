# Generation IV additional anime references

Twenty additional Sinnoh anime Pokédex captures, downloaded from WikiDex's original file URLs on 2026-09-09. `gen4.json` records each WikiDex file page, direct CDN URL, local filename, source SHA-1, episode, and dimensions. The local files are unchanged downloads.

The set covers episodes 473, 477, 482, 484, 490, 518, 564, 569, 585, 588, 594, 606, 624, 646, 652, 653, 654, and 658. EP606 and EP484 each contribute two different scan states. The collection adds no alternate crops, resized copies or mirrors to inflate the count. All entries are episode captures.

These references show anime continuity only. They can support screen-state, scan-screen, palette, and framing decisions for the Sinnoh Pokédex treatment. They do not prove game hardware geometry, casing dimensions, hinge construction, or a universal anime model. Several files are small source captures, so fine detail may be unreadable at larger display sizes.

WikiDex file pages are the provenance records. Direct media URLs point to the original WikiDex CDN uploads used for the local copies. Existing catalogue material and the earlier Ash/Paul Sinnoh captures were excluded from this pass; every selected item has a distinct source page, direct URL, and SHA-1 in `gen4.json`.
