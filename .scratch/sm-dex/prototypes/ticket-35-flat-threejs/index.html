Comparison notes & input checks

Flat uses new SVG/DOM geometry. Three.js uses extruded parts with the same control coordinates. Hybrid keeps the flat casing and uses genuine Three.js caps. The fourth version reverses that pairing: the Three.js casing carries flatter-colour raised caps. All four recreate 26's dark menu/list/detail UI. Round caps and the connected D-pad have raised geometry; full 3D has stronger casing rims and closing clearance. Depth and the matching lid are interpreted from references, not a pixel-identical trace. No retired imagery is loaded.

Arrows navigate, A opens, Escape or B returns. Focused buttons use Space or Enter. Clicks activate on release. Dragging off cancels. Closing preserves the current entry. Power is separate. Small-screen use has a readable view with larger controls.
